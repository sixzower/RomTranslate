ใช้กรอบ 8×16 ฟอนต์หลัก Quetzal TH ที่ดึงและปรับจาก ROM ที่คุณส่งมา สระและวรรณยุกต์ประกอบกับพยัญชนะในเกม กรอบ 15px/12px มีการย่อแนวตั้ง ควรตรวจไม่ให้เครื่องหมายซ้อนกัน โหมดเงาจาก ROM เก็บเงาที่ดึงจากต้นฉบับ เมื่อแก้รูปอักษร ระบบใช้รูปที่วาดใหม่แทนภาพต้นฉบับ ส่วนโหมดเงาทิศทางต่าง ๆ สร้างหลังประกอบอักษร และตัดที่ขอบความสูงของฟอนต์เกม สีเงาในเกมอิงสีของหน้าจอนั้น ภาพ PNG และ BIN เป็นรูปอักษรต้นฉบับไม่มีเงา ต้องเก็บคู่กับ JSON ที่บันทึกทิศทางเงา เพื่อรู้ว่าแต่ละภาพคืออักษรใด

ROM ติดตั้งรูปอักษรไทย อักษรอังกฤษ ตัวเลขและช่องว่างในเกมยังใช้ฟอนต์เดิม การแก้รูปกลุ่มนี้เก็บส่งออกใน JSON/PNG/BIN ได้

เก็บร่างในเบราว์เซอร์เครื่องนี้อัตโนมัติ การวาดยังไม่เปลี่ยนฟอนต์ที่ใช้อยู่จนกดบันทึกเป็น preset ดาวน์โหลด JSON เก็บสำรองได้โดยไม่ต้องเปิด ROM

เลือกส่วนที่ตั้งใจแปล

เลือกหมวดที่อยากแปล เพื่อคิดเปอร์เซ็นต์เฉพาะงานของคุณ

เปอร์เซ็นต์ = จำนวนข้อความที่มีคำแปลฉบับจริง ÷ จำนวนข้อความในหมวดที่เลือก × 100 นับแต่ละตำแหน่ง ROM ครั้งเดียว แม้ส่งออกหลายไฟล์หรือมีหลาย pointer ใช้ร่วมกัน

การเลือกนี้เปลี่ยนเฉพาะเป้าหมายคำนวณเปอร์เซ็นต์ ไม่ลบคำแปล และไม่เปลี่ยนช่วงส่งออก Excel เก็บเป้าหมายไว้กับโปรเจกต์และ ROM ที่สร้างใหม่

ไฟล์งาน / งานค้าง

เก็บคำแปล ร่าง ฟอนต์ และส่วนที่ทำค้างไว้ เปิดต่อด้วย ROM ต้นฉบับเดียวกันได้

บันทึกคำแปล ร่าง AI ฟอนต์ หมวดเป้าหมาย รายการข้อความ ช่วง Excel และจุดที่ทำค้างไว้ เปิดต่อข้ามเครื่องได้ โดยเลือก ROM ต้นฉบับเดียวกันอีกครั้ง ไม่อัปโหลด ROM

ที่เครื่องอื่นกด “เปิดโปรเจกต์” เลือก JSON นี้ แล้วเปิด ROM ต้นฉบับ ถ้าใช้คลาวด์ให้เปิดไฟล์งานจากรายการด้านล่างแทน

รายการของงานถูกตรึงด้วยรหัสข้อความ ช่วง 1–200 จึงยังเป็นชุดเดิมแม้แปลเพิ่ม พัก / ปิด / ยกเลิกงานจะหยุดจำกัดผลกรอง ไม่ลบคำแปลหรือร่างที่เก็บแล้ว

เลือกฟอนต์สำหรับตัวอย่างและไฟล์เกมที่สร้างใหม่

ส่งออกภาพ / ไทล์ฟอนต์

เปลี่ยนชื่อ preset

ชื่อฟอนต์ที่ติดมากับเว็บจำไว้ในเครื่องนี้ ฟอนต์ที่นำเข้าเองจะบันทึกชื่อใหม่และซิงก์เป็นเวอร์ชันใหม่เมื่อเชื่อมคลาวด์ สำเนาเดิมบนคลาวด์ยังเก็บไว้

คลังฟอนต์ส่วนตัวบนคลาวด์

ตั้งค่าที่เก็บออนไลน์ / วิธีเริ่มใช้

1. ใช้โปรเจกต์ Supabase เดิม เปิด SQL Editor รัน SQL ตามโหมดที่เลือก: แบบไม่ใช้อีเมลใช้ font-code-library.sql ในหัวข้อด้านล่าง ส่วนแบบบัญชีใช้อีเมลใช้ font-library.sql เพื่อเพิ่มตาราง romtranslate_font_library และสิทธิ์ส่วนตัว ไม่ต้องเปลี่ยนการตั้งค่าเว็บอื่น บัญชีผู้ใช้เป็นชุดเดียวกันในโปรเจกต์นี้
2. ใน Project Settings → API คัดลอก Project URL และ publishable key (หรือ anon key) มาใส่ด้านล่าง ห้ามใช้ secret หรือ service_role key
3. ใส่รหัสคลังส่วนตัวจาก SQL โดยไม่ต้องสมัครอีเมล หรือเลือกใช้บัญชีแบบเดิม ใช้ URL และ key ชุดเดียวกันที่เครื่องอื่น

ค่า URL และ key สาธารณะเก็บบนเครื่องนี้ โหมดรหัสคลังจำรหัสไว้ในเครื่องจนกดตัดการเชื่อมต่อ โหมดอีเมลเก็บเซสชันเฉพาะแท็บและใช้ Row Level Security

ใช้คนเดียว — ไม่ต้องสมัครอีเมล

รัน SQL สำหรับคลังแบบใช้รหัส ใน Supabase แล้วคัดลอก private_library_code จากผลลัพธ์มาใส่ที่นี่ เก็บรหัสไว้ใช้ที่เครื่องอื่น ผู้ที่มีรหัสนี้เข้าถึงคลังได้

จำรหัสบนเครื่องนี้ ไม่ต้องกรอกซ้ำเมื่อกลับมาใช้ ไม่มีระบบกู้รหัสผ่านอีเมล รัน SQL ซ้ำจะสร้างคลังใหม่แยกจากเดิม

ตัวเลือกเดิม: เข้าบัญชีด้วยอีเมล

เพิ่มฟอนต์แบบไม่ทับเวอร์ชันเก่า และไม่เปลี่ยนฟอนต์ที่ใช้อยู่จนกดเลือก การลบ preset ในเครื่องไม่ลบสำเนาบนคลาวด์

รายละเอียดเพิ่มเติม

ใช้รหัสคลังเดียวกัน (หรือบัญชีเดียวกัน) และโปรเจกต์ Supabase เดียวกันบนทุกเครื่อง ฟอนต์ที่บันทึกเป็น preset จะซิงก์เมื่อเชื่อมต่อ ร่างที่ยังไม่ได้บันทึกจะอยู่เฉพาะเครื่อง ROM และคำแปลจะไม่ถูกส่งขึ้นคลังนี้

นำเข้าฟอนต์ภายนอก

ใช้ไฟล์ฟอนต์ JSON 8×16 ดาวน์โหลดตัวอย่างหรือวาดในห้องฟอนต์ได้

รองรับไฟล์ .json bitmap 8×16 แบบเดียวกับ thai_font_data.json ที่ส่งมา ดาวน์โหลดตัวอย่างด้านล่างแล้วแก้ภาพอักษรใน rows ได้

รายละเอียดเพิ่มเติม

ต้องมี name, glyphWidth: 8, glyphHeight: 16 และ glyphs แต่ละอักษรมี char และ rows จำนวน 16 แถว แถวละ 8 ตัว ใช้ 0 = โปร่งใส และ 1 = สีอักษร ต้องมีอักษรไทย สระ วรรณยุกต์ ตัวเลข และช่องว่างครบตามตัวอย่าง ห้ามมี char ซ้ำ เพิ่ม spacing: "compact" สำหรับระยะกระชับ หรือ "native" สำหรับฟอนต์ที่มี advance จาก ROM หรือ "fixed" สำหรับระยะเดิม 8px ได้ หากไม่ระบุจะใช้ compact

Preset ที่ดึงจาก ROM มี layout: "native", nativeHeight: 14 หรือ 15, shadow: "source" และ nativePixels ของแต่ละอักษร 16 แถว × 16 ตัว (0 โปร่งใส, 1 สีอักษร, 2 เงา) พร้อม advance 1–16px ภาพอักษรผสม native ใช้เมื่อรูปต้นฉบับยังไม่ถูกแก้ ในห้องออกแบบเมื่อแก้รูปจะใช้ rows ที่วาดแทนภาพเดิม ส่วน PNG/BIN เป็นภาพ rows สำหรับออกแบบ ไม่รวมชั้นเงา จึงควรเก็บ JSON คู่กัน

PNG/BIN อย่างเดียวไม่มีข้อมูลว่าแต่ละภาพคืออักษรใด จึงยังนำเข้าโดยตรงไม่ได้ ZIP ให้แตกไฟล์แล้วเลือก JSON ส่วน TTF/OTF/WOFF ต้องแปลงเป็น bitmap รูปแบบนี้ก่อน เกมใช้กรอบ 15px/12px จึงมีการปรับแนวตั้งและประกอบสระ/วรรณยุกต์ ตรวจในเกมหลังเปลี่ยนฟอนต์

ฟอนต์หลักคือ Quetzal TH 1.0.3 — adapted 8×16 แยกสระ/วรรณยุกต์จากรูปที่ประกอบไว้ใน ROM และปรับอักษรหายากที่ไม่มีในต้นฉบับให้ครบ รูปและการจัดวางจึงไม่ตรงต้นฉบับทุกกลุ่มอักษร Sword & Shield TH และ Emerald Seaglass TH ติดมากับเว็บและไฟล์ดาวน์โหลดทุกเครื่อง ไม่ต้องอัปโหลดซ้ำ เก็บพิกเซลและเงาที่ดึงจาก ROM อักษรที่ยังไม่ยืนยันจะแจ้งเมื่อเลือก preset โดยไม่แทนรูปจากฟอนต์อื่น กลุ่มอักษรที่มีภาพต้นฉบับจับคู่แล้วใช้ภาพเดิม กลุ่มอื่นประกอบจากชิ้นส่วน และกรอบ 12px ย่อแนวตั้ง Preset ที่นำเข้าเองเก็บในเบราว์เซอร์บนเครื่องนี้ โปรเจกต์และ ROM รุ่นใหม่แนบฟอนต์ที่เลือกไว้ด้วย เพื่อเปิดบนเครื่องอื่นได้ ล้างข้อมูลเว็บจะลบ preset บนเครื่อง ควรดาวน์โหลด JSON สำรอง
