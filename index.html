ข้อมูล ROM

ถอดรหัสด้วยตาราง Pokémon Gen III English รายการที่มี script pointer ยังต้องตรวจในเกม ข้อความอื่นเป็นผลสแกนที่ต้องตรวจสอบ ไฟล์ ROM อยู่บนอุปกรณ์ของคุณ

Settings / AI

รองรับ API รูปแบบ OpenAI Chat Completions ต้องใช้บริการที่อนุญาต CORS สำหรับเบราว์เซอร์

คำขอจะส่งข้อความที่เลือกและอภิธานศัพท์ไปยัง URL นี้ ไม่ส่งไฟล์ ROM คีย์ไม่รวมในโปรเจกต์และจะหายเมื่อปิด/รีโหลดเว็บ

ถ้าไม่มี API ใช้โหมดคัดลอกพรอมป์ต์ แล้ววางคำตอบลงช่อง AI ด้วยตนเองได้

ฟอนต์ไทย 8×16 ของคุณ

ใช้ฟอนต์จาก files.zip เป็นค่าเริ่มต้น ทั้งตัวอย่างเว็บและ ROM สระ/วรรณยุกต์ซ้อนบนพยัญชนะ โดยปรับกรอบให้เข้ากับฟอนต์เกม 15px และฟอนต์สำรอง 12px

นำเข้าฟอนต์ภายนอก

รองรับไฟล์ .json bitmap 8×16 แบบเดียวกับ thai_font_data.json ที่ส่งมา ดาวน์โหลดตัวอย่างด้านล่างแล้วแก้ภาพอักษรใน rows ได้

ต้องมี name, glyphWidth: 8, glyphHeight: 16 และ glyphs แต่ละอักษรมี char และ rows จำนวน 16 แถว แถวละ 8 ตัว ใช้ 0 = โปร่งใส และ 1 = สีอักษร ต้องมีอักษรไทย สระ วรรณยุกต์ ตัวเลข และช่องว่างครบตามตัวอย่าง ห้ามมี char ซ้ำ

PNG/BIN อย่างเดียวไม่มีข้อมูลว่าแต่ละภาพคืออักษรใด จึงยังนำเข้าโดยตรงไม่ได้ ZIP ให้แตกไฟล์แล้วเลือก JSON ส่วน TTF/OTF/WOFF ต้องแปลงเป็น bitmap รูปแบบนี้ก่อน เกมใช้กรอบ 15px/12px จึงมีการปรับแนวตั้งและประกอบสระ/วรรณยุกต์ ตรวจในเกมหลังเปลี่ยนฟอนต์

Preset เก็บในเบราว์เซอร์บนเครื่องนี้ โปรเจกต์และ ROM รุ่นใหม่แนบฟอนต์ที่เลือกไว้ด้วย เพื่อเปิดบนเครื่องอื่นได้ ล้างข้อมูลเว็บจะลบ preset บนเครื่อง ควรดาวน์โหลด JSON สำรอง

พรอมป์ต์สำหรับ AI

ยังไม่ได้ตั้งค่า API ใช้พรอมป์ต์นี้กับผู้ช่วย AI ภายนอก แล้ววางคำตอบลงช่องแปลตรง/ตามบริบท

สร้าง ROM ทดสอบ

รองรับไฟล์ Imperium v1.3.1 ที่ตรงกับ SHA-256 ที่ตรวจสอบแล้ว ติดตั้งกลุ่มตัวอักษรไทยในช่องฟอนต์ว่าง ย้ายข้อความแบบ pointer ไปพื้นที่ว่าง ชื่อที่เก็บในตารางยังต้องไม่เกินขนาดช่องเดิม ตรวจรหัสพิเศษก่อนส่งออกทุกครั้ง
